## ⏱️ Video Script & Visual Cues (Total: ~3 Minutes)

### [00:00 – 00:30] PART 1: Quick Intro & The Problem
* **On Screen:** Start on the God's Eye landing page (`http://localhost:8000`). Show the clean dark eclipse background and glass pill search bar.
* **Narration:**
  > *"Hey everyone, I'm Ayushman. If you look at most AI agents today, they suffer from complete amnesia. You ask an agent to check a competitor's website, and it gives you a snapshot of what they sell today. But if you run it next week or next month, it has zero memory of past pricing, past promotions, or messaging changes.*
  > 
  > *To fix this, we built **God's Eye**—a competitive intelligence pipeline powered by **Vectorize Hindsight** for persistent long-term memory."*

---

### [00:30 – 01:10] PART 2: Live Pipeline Execution
* **On Screen:** Type `https://www.bmw.in` into the glass search bar and click Search (or press Enter).
* **Narration:**
  > *"Let's test this with BMW India. Instead of a basic scraper, God's Eye coordinates an automated intelligence pipeline:*
  > * *First, it pulls verified 2026 market articles using the Tavily search API.*
  > * *Second, it calls our Vectorize Hindsight Cloud memory bank to recall past stored observations.*
  > * *Third, it executes Hindsight's native `reflect` endpoint to synthesize how competitors shifted over time.*
  > * *Finally, it extracts structured rival profiles using Groq's 120B model and commits the new scan to memory."*

---

### [01:10 – 02:00] PART 3: The 'Aha!' Moment — Hindsight Memory in Action
* **On Screen:** The dashboard appears. Scroll to the **Hindsight Memory Radar** card.
* **Narration:**
  > *"Here's our executive dashboard. Notice the right panel: these are real, clickable news articles directly from Tavily.*
  > 
  > *Now look at the core of the system: **The Hindsight Memory Radar**. Look at the Live Hindsight Reflection box: this text is generated directly by Hindsight Cloud's `/reflect` endpoint, comparing past memory nodes with today's scan.*
  > 
  > *Below it, you can see the actual memory node objects stored on Hindsight Cloud with their real IDs and timestamps. In Scan 1, it recorded baseline pricing; in Scan 2, it detected that Mercedes increased luxury sedan prices by 2.4% while Audi launched a ₹2.5 Lakh discount incentive. That temporal delta only exists because Hindsight remembers."*

---

### [02:00 – 02:35] PART 4: Interrogating the Memory Bank
* **On Screen:** Scroll down to the **"Interrogate God's Eye Memory Bank"** section. Click the chip: *"What is Audi's biggest vulnerability right now?"* and hit Interrogate.
* **Narration:**
  > *"We also built an interactive drilldown bar so an executive can question the memory bank directly. Watch: I'll ask 'What is Audi's biggest vulnerability right now?'*
  > 
  > *God's Eye queries Hindsight's reflection engine, correlates Audi's recent discounting with tariff headwinds on imported EVs, and provides an actionable counter-strategy grounded directly in stored memory nodes."*

---

### [02:35 – 03:00] PART 5: Key Takeaway & Wrap-Up
* **On Screen:** Scroll back to the top overview.
* **Narration:**
  > *"My biggest lesson building this: stateless agents give you snapshots, but strategy requires trajectory. By using Hindsight's `retain`, `recall`, and `reflect` primitives, we turned a simple web crawler into an agent that actually compounds intelligence over time.*

  > *Check out the code in the GitHub repo below, read our technical article on Dev.to, and check out Vectorize Hindsight. Thanks for watching!"*
